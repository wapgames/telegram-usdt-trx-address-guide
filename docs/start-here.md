# 使用前先看：USDT / TRX 地址查询与监听怎么选

如果你第一次在 Telegram 里使用 USDT / TRX 地址查询机器人，建议先弄清楚自己要解决的问题。

不同功能适合不同场景：
临时查一笔到账，通常用 **地址查询**；
长期关注一个地址变化，通常用 **地址监听**；
转账时提示手续费不足，则需要了解 **TRX** 和 **能量租用**。

> 🛡️ **安全提醒**
> 查询公开地址不需要私钥、助记词、交易所密码或验证码。任何要求你提供这些信息的机器人、客服或陌生人，都应该谨慎对待。

## 🧭 你现在遇到的是哪种问题

可以先对照下面这张表：

| 你遇到的问题               | 建议先看         |
| -------------------- | ------------ |
| 对方说已经转 USDT，但你还没看到到账 | 🔍 地址查询      |
| 想确认某个地址最近有没有收款       | 🔍 地址查询      |
| 想知道某个地址有没有转出记录       | 🔍 地址查询      |
| 需要长期关注一个地址的资金变化      | 🔔 地址监听      |
| 转账时提示 TRX 不足         | 💸 TRX 手续费说明 |
| 转 TRC20 USDT 成本较高    | ⚡ 能量租用说明     |
| 担心机器人是否会影响钱包安全       | 🛡️ 安全注意事项   |

如果只是临时查一次地址，通常先用 **地址查询**。
如果你需要长期接收提醒，比如地址到账、转出或余额变化，才更适合使用 **地址监听**。

## 🔍 地址查询适合什么情况

地址查询适合临时核对某个钱包地址的链上记录。

常见用途包括：

* 查看某个 TRC20 USDT 地址是否收到款；
* 核对一笔转账是否已经上链；
* 查看地址最近是否有转出记录；
* 判断一个地址是否有历史交易；
* 帮团队成员快速确认收款情况。

> 地址查询只能查看公开链上信息。它不能控制钱包，也不能阻止或追回转账。

## 🔔 地址监听适合什么情况

地址监听适合长期关注某个地址。

例如：

* 你有一个固定收款地址，需要及时知道是否到账；
* 团队需要关注业务地址是否有资金转出；
* 你不想频繁手动打开区块浏览器；
* 希望在 Telegram 里收到地址变动提醒。

> 地址监听的作用是提醒，不是风控系统。它不能拦截交易，也不能保证资金安全。

## 💸 TRX 手续费和能量租用什么时候需要了解

如果你只是查询地址，一般不需要关心 TRX 和能量。

但如果你要转账 TRC20 USDT，就需要了解它们：

| 概念      | 说明                      |
| ------- | ----------------------- |
| 💸 TRX  | TRON 网络的基础资产，常用于支付链上手续费 |
| ⚡ 能量    | TRC20 USDT 转账时可能消耗的链上资源 |
| 📶 带宽   | 普通转账或账户操作中可能涉及的网络资源     |
| 🔁 能量租用 | 在部分转账场景中，用来降低链上资源成本     |

简单来说：

| 情况            | 需要关注什么       |
| ------------- | ------------ |
| 只是查地址         | 不一定需要 TRX    |
| 要转 TRC20 USDT | 需要关注 TRX 或能量 |
| 钱包提示手续费不足     | 先检查 TRX 余额   |
| 经常转 USDT      | 可以了解能量租用是否适合 |

## 🛡️ 使用机器人时不要发送哪些信息

查询公开地址通常不需要敏感信息。

无论使用什么 Telegram 机器人，都不要发送：

| ❌ 不要发送 | 原因           |
| ------ | ------------ |
| 私钥     | 可能导致钱包资产被转走  |
| 助记词    | 等同于钱包控制权     |
| 交易所密码  | 可能导致账号被盗     |
| 短信验证码  | 可能被用于登录或转账确认 |
| 邮箱验证码  | 可能被用于重置密码    |
| 钱包授权链接 | 可能诱导你授权恶意合约  |

查询地址只需要公开钱包地址或交易哈希。
如果有人要求你提供私钥或助记词，应立即停止操作。
