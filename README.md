## 推荐使用流程

### 1. 先确认你要解决的问题

在使用机器人之前，建议先判断你的目标属于哪一种：

| 目标 | 建议入口 |
|---|---|
| 查一个地址是否收过 USDT | 地址查询 |
| 长期观察一个地址是否有资金变化 | 地址监听 |
| 转账时提示 TRX 不足 | TRX 兑换 |
| 想降低 TRC20 转账成本 | 能量租用 |
| 想确认 Telegram 用户或群成员 ID | ID 查询 |

### 2. 查询地址前先确认网络

USDT 有多个链上版本，常见的包括 TRC20、ERC20 等。截图中的机器人重点围绕 **USDT 与 TRX**，因此更适合处理 TRON 网络上的 TRC20 USDT 地址。

如果你拿到的是 ETH 地址、BSC 地址或交易所内部转账记录，查询结果可能无法对应到 TRON 链上的真实交易。

### 3. 使用地址监听减少重复查询

如果你只是偶尔查一次地址，使用“地址查询”即可。  
如果你需要持续知道某个地址是否收款、是否转出、余额是否变化，更建议使用“地址监听”。这样可以减少人工刷新区块浏览器的次数，也方便在 Telegram 中及时收到提醒。

### 4. 转账前检查 TRX 与能量

TRC20 USDT 转账通常需要消耗链上资源。实际操作前，建议先确认：

- 地址里是否有足够 TRX；
- 是否需要租用能量；
- 目标地址是否填写正确；
- 是否已经小额测试过第一次转账。

不要把私钥、助记词、交易所登录密码发送给任何机器人或陌生人。

## 常见问题

### Telegram 机器人能直接控制我的钱包吗？

通常不能。地址查询和地址监听只需要公开地址即可完成。公开地址可以用于查看链上记录，但不能转走资产。真正需要保护的是私钥、助记词、交易所账号和验证码。

### 为什么我查不到某笔 USDT 交易？

常见原因包括：

1. 地址网络不一致，例如把 ERC20 地址拿去查 TRON 网络；
2. 交易还没有被区块确认；
3. 查询的是交易所内部账变，不是链上转账；
4. 地址复制错误，或者多复制了空格、标点。

可以先核对地址格式，再到区块浏览器交叉确认。

### 地址监听适合监控哪些场景？

地址监听适合用于到账提醒、收款地址观察、团队财务记录、异常转出提醒等场景。它不适合替代风控系统，也不应作为投资判断依据。

### 能量租用和 TRX 兑换有什么区别？

简单理解：TRX 是链上手续费相关资产，能量是 TRON 网络中执行合约时会用到的资源。TRC20 USDT 转账可能涉及能量消耗。能量租用通常用于降低某些转账场景的成本，而 TRX 兑换用于补充地址里的 TRX。
